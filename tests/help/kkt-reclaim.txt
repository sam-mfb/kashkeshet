Take over an avatar using a private recovery file; print only its handle

Usage: kkt reclaim [OPTIONS] --handle <HANDLE> --recovery-file <RECOVERY_FILE> --token-file <TOKEN_FILE>

Options:
      --handle <HANDLE>                The avatar's handle, such as amber-falcon
      --recovery-file <RECOVERY_FILE>  Private file containing only the recovery code
      --token-file <TOKEN_FILE>        New private file for the replacement token; refuses an existing path
      --config <CONFIG>                The serve config file (otherwise the default, if present)
      --url <URL>                      The HTTP MCP endpoint (otherwise http://<serve bind>/mcp)
      --key-file <KEY_FILE>            The access key file (otherwise the one used by serve)
  -h, --help                           Print help
